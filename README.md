
# Clearpath ROS 2 CLI extensions

This repo contains extensions to the [ros2cli](https://github.com/ros2/ros2cli) package developed by the Clearpath team.

Packages available:
- [ros2diagnostics](./ros2diagnostics/README.md) - a command to view diagnostics.
- [ros2graph](./ros2graph/README.md) - generates DOT graph showing connections of ROS 2 topics, services and actions. 
- [ros2rosout](./ros2rosout/README.md) - provides a convenient way to monitor the ROS 2 logs.
